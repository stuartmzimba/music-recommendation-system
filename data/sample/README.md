# Sample Data

This directory contains sample data for the Music Recommender System.

## Files

- `south_african_songs.csv` - Sample South African music dataset
- `user_listening_history.csv` - Sample user listening history for training
- `spotify_features.csv` - Sample Spotify audio features

## Data Sources

The sample data is based on:
- South African music charts
- Popular Amapiano and Afrobeats tracks
- Simulated user listening patterns

## Usage

This sample data is used for:
1. Initial system testing
2. Demo purposes
3. Development and debugging

For production use, replace with real data from:
- Spotify API
- Music streaming platforms
- User interaction logs
